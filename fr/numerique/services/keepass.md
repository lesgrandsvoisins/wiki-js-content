# KeePass

/ [home](../../home.md) / [numerique](../../numerique.md) / [services](../services.md) / KeePass (Maux de passe)

Nous utilisons une stratégie **webdav**, ce qui peut proscrire une application en particulier.

## Desktop 

Merci d'utiliser [**KeePass Password Safr**](https://keepass.info) sur une desktop.

Utilisez votre accès [webdav.gv.je](/numerique/webdav) pour le lieu du fichier avec votre LOGIN@gv.je et le password spécifique à SFTPgo. 

## Client web KeeWeb

[KeeWeb](https://keeweb.info/) avec son [app.keyweb.info](https://app.keeweb.info/) peut transformer le navigateur dans une application KeePass, même mobile.

## Client Android Keepass2Android

Utilisez Keepass2Android sur Android.

Ouvrir https://webdav.gv.je pour le fichier.



## Autres clients sur Linux

Applications Linux à éviter :

* KeePassXC : ne supporte pas Webdav
* AuthPass : un produit d'appel sans Webdav
* KeepSecret : juste pour les portefeuilles KDE
* Secrets : Pas de webdav

Autre mention :

* RustConn : pour les connexions, mais mentionne PeePassXC
* ProjectPad : Looks good for configuration management
