# Assistance à distance

Une manière d'aider à distance est de pouvoir contrôler l'ordinateur distant ensemble.

Un outil qui aide avec le contrôle distant est Google Chrome Remote Desktop.

https://remotedesktop.google.com/

**Attention : ce dispositif donne le controle sur votre ordinateur à une personne à distance. Faites avec une précaution tres importante**

Lors du premier usage, il y a plusieurs manipulations à faire :

1. Installer Chroem Remote Desktop sur l'ordinateur. Cela peut aussi faire ajouter l'extension Chrome Remote Desktop à Chrome. il peut être nécessaire de s'authentifier avec son compte google, habituellement gmail.
2. Sélectionner « partager mon bureau » puis « Generer un code de partage». Une fois le code généré, lisez le code à l'autre personne, puis rester sur la.même page jusqu'à que une fenêtre demande de confirmer le partage. Cliquer sur confirmer le partage.
