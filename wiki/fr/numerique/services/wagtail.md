# Sites webs comme Les Grands Voisins et d'autres avec un système de gestion de contenu Wagtail

/ [home](../../index.md) / [numerique](../../numerique.md) / [services](../services.md) / WWW (Wagtail) gestion de contenus web

Le site web https://www.lesgrandsvoisins.com est géré par Wagtail. 

Son tableau de bord / interface d'adminstration se trouve sur https://www.lesgrandsvoisins.com/cms-admin/ . Il est accessible sur compte unifié.

Pour créer un compte Wagtail, il convient de s'identifier une première fois avec son compte unifié. Cela peut être nécessaire pour la gestion de sa fiche annuaire.

D'autres associations avec des sites indépendants peuvent se trouver sur le serveur des Grands Voisins avec accès à leurs sites par https://www.lesgrandsvoisins.com/cms-admin .
